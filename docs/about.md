# 关于 Awesome Android Root

Awesome Android Root 是一个由社区精心维护的一流资源，致力于 Android root、深度定制和用户赋能。它提供了一个全面且持续更新的目录，收录了超过 600 个经过审核的工具、应用、模块和专家指南，专为希望释放设备全部潜力的高级用户和开发者而设计。

## 我们的使命

我们的使命是通过提供免费、可靠且全面的资源，让高级 Android 定制大众化。我们帮助全球用户通过 root、第三方 ROM 和系统级修改掌控自己的设备，并构建一个以知识共享和技术自由为基础的社区。

## 我们提供什么

**全面的 Root 与定制资源**
*   **[专家指南](./rooting-guides/index.md)**：面向各种设备和方法详尽的分步教程。
*   **[650+ 精选 Root 应用与模块](/apps-and-modules/root-management)**：精心挑选的合集，涵盖广告拦截、隐私、性能、自动化等。
*   **[广泛的设备支持](./rooting-guides/#机型专属指南)**：针对小米、三星、Pixel、OnePlus 和 Motorola 等主流品牌的专属指南。
*   **[常见问题与故障排除](./faqs.md)**：用于解决常见问题并寻求支持的专属资源。

## 快速上手

**新用户的基本路径：**

## 社区与支持

我们是充满活力的 Android 开发者和爱好者生态的一部分，类似于 XDA Developers 这样的社区——一个分享移动开发创意的大型国际论坛。

**官方渠道：**
*   [🌐 GitHub](https://github.com/awesome-android-root/awesome-android-root)：参与项目的源代码与开发。
*   [𝕏](https://x.com/awsm_and_root)：及时了解最新动态和社区精选内容。

**需要帮助？**
*   查阅我们的[常见问题](./faqs.md)获取即时解答。
*   在 [XDA Forums](https://forum.xda-developers.com/) 的海量存档中搜索设备专属解决方案。

## 核心价值观

*   **安全第一：** 我们优先采用经过验证的来源，倡导安全、负责任的做法，以降低无限重启等风险。
*   **社区驱动：** 作为开源项目，我们依赖全球 Android 社区的协作与贡献。
*   **注重教育：** 我们致力于提供深入的教育资源，促进学习与掌握。
*   **持续更新：** 我们的内容定期维护，以反映 Android root 领域最新的工具、方法和发展动态。
