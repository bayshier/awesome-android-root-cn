# 文件管理

面向已 root Android 设备的**文件管理** - 拥有完整 root 权限的文件管理器、存储清理应用和
Magisk/KernelSU 模块，以及面向高级用户的文件与分区工具。

> [!TIP]
> 相关内容：[备份与恢复](/apps-and-modules/backup.md)可在你清理或刷入任何内容之前保护你的文件和应用数据。


## 清理

- **[⭐ SD Maid 2/SE](https://github.com/d4rken-org/sdmaid-se)** - 一款专注于维护的 Android 文件管理工具，核心用途是释放空间和清除不需要的数据。`FOSS` | [🌱](https://f-droid.org/en/packages/eu.darken.sdmse/) | [▶️](https://play.google.com/store/apps/details?id=eu.darken.sdmse)
- **[AutoPurge Pro](https://github.com/S123123sd/SmartClear)** - 垃圾清理自动化工具，为 Android 设备提供深度清理和资源管理能力。`FOSS` `[M]` `[K]`
- **[Basic Cleaner](https://github.com/WeirdMidas/BasicCleaner)** - 每 7/15/30 天自动执行一组清理和修复操作的 Magisk/KSU 模块。`FOSS` `[M]` `[K]`
- **[Cache Cleaner Widget](https://gitlab.com/Zinaro/CacheCleanerWidget)** - 无 UI 的 root 小部件，一键清除所有应用缓存。`FOSS` | [🌱](https://f-droid.org/packages/com.zinaro.cachecleanerwidget/)
- **[Cleaner Royall](https://github.com/araafroyall/Cleaner-Royall)** - 轻量但极速而强大的 Android 清理工具。`Proprietary` `[LSP]`
- **[ClearBox](https://github.com/FLYCOM-E/ClearBox)** - 可删除所有软件缓存、安装包、压缩包、垃圾文件、空文件夹等。`Proprietary` `[M]` `[K]`
- **[CZero](https://github.com/Xocio/CZero)** - 清理常用应用的缓存，并提供后台抑制、空文件夹清理和 F2FS 垃圾回收。`FOSS` `[M]` `[K]`

## 文件与分区工具

- **[Partition Backup](https://github.com/rhythmcache/partition-backup)** - 该实用工具允许你保存 Android 设备分区。`FOSS` `[M]`
- **[SD Flasher](https://github.com/theblazehen/sd_flasher)** - 从 Android 设备将磁盘镜像（.img、.img.gz、.img.xz、.zip）直接刷入 SD 卡。`FOSS`
- **[StorageFixer](https://github.com/omersusin/StorageFixer)** - 一款 root 应用（含可选 Xposed 模块），用于修复 AOSP 类 ROM 上 Android 16 QPR1+ 遗留的损坏的 `Android/data`、`Android/obb` 和 `Android/media` 目录及 appops。`FOSS` `[LSP]`
- **[StorageRedirect](https://github.com/AcE77505/storage-redirect-module)** - 将应用的外部存储目录重定向到其自身私有数据目录，绕过 Android 11+ 的 FUSE 转发层。`FOSS` `[LSP]`
- **[USB Mass Storage](https://github.com/Enginex0/UsbMassStorage)** - 将你的手机变成 U 盘。

## 文件管理器

- **[⭐ MiXplorer](https://mixplorer.com/)** - 功能丰富的文件管理器。`Proprietary`
- **[AnExplorer](https://github.com/1hakr/AnExplorer)** - 简单、小巧、快速且高效的文件管理器。`FOSS` | [▶️](https://play.google.com/store/apps/details?id=dev.dworks.apps.anexplorer)
- **[File Manager](https://play.google.com/store/apps/details?id=com.alphainventor.filemanager&hl=en)** - 适用于 Android 设备的易用且强大的文件管理器。免费、快速、功能齐全，界面简洁，极易上手。`Proprietary`
- **[File Manager - File Browser](https://play.google.com/store/apps/details?id=com.alc.filemanager)** - 像在台式机或笔记本电脑上一样管理文件（文件浏览器），支持多选、剪切/复制/粘贴、移动、创建、删除、重命名、搜索等操作。`Proprietary`
- **[Fossify File Manager](https://github.com/FossifyOrg/File-Manager)** - 无广告、尊重隐私与安全的易用文件管理应用。`FOSS` | [🌱](https://f-droid.org/packages/org.fossify.filemanager/) | [▶️](https://play.google.com/store/apps/details?id=org.fossify.filemanager)
- **[Material Files](https://github.com/zhanghai/MaterialFiles)** - 支持 root 的现代文件管理器。`FOSS` | [🌱](https://f-droid.org/packages/me.zhanghai.android.files)| [▶️](https://play.google.com/store/apps/details?id=me.zhanghai.android.files)
- **[MT Manager](https://mt2.cn/)** - Android 文件管理与逆向工程工具。`Proprietary`
- **[NoStorageRestrict](https://github.com/Xposed-Modules-Repo/com.github.dan.nostoragerestrict)** - 在 Android 11 及以上版本中，移除通过文件管理器选择文件夹（Sdcard、Download、data 和 obb）时的限制。`FOSS`
- **[Remember My Sort](https://github.com/hxreborn/remember-my-sort)** - 强制 Android 原生文件选择器记住你的排序偏好。`FOSS` `[LSP]` | [🌱](https://apt.izzysoft.de/packages/eu.hxreborn.remembermysort)
- **[Root Explorer](https://play.google.com/store/apps/details?id=com.speedsoftware.rootexplorer)** - 拥有 root 权限的文件管理器。`Proprietary`
- **[RS File Manager File Explorer](https://play.google.com/store/apps/details?id=com.rs.explorer.filemanager)** - 免费、安全、简单，用 RS File Manager 高效轻松地管理文件。`Proprietary`
- **[Solid Explorer](https://play.google.com/store/apps/details?id=pl.solidexplorer2)** - 支持 root 的强大文件管理器。`Proprietary`
- **[Sortify](https://github.com/xCaptaiN09/Sortify)** - 自动整理 Download 文件夹中的文件。`FOSS` `[M]` `[K]`
- **[Total Commander](https://play.google.com/store/apps/details?id=com.ghisler.android.TotalCommander)** - 功能丰富的 Android 文件管理器。如需更好的体验，请阅读[此帖](https://www.ghisler.ch/board/viewforum.php?f=22)。`Proprietary`
- **[Ultimate File Manager Pro](https://github.com/Kilowatch/ultimate-file-manager-pro)** - 面向 Android 手机、Android TV 和 Windows PC 的双栏文件管理器。`FOSS`
- **[ZArchiver](https://play.google.com/store/apps/details?id=ru.zdevs.zarchiver)** - 一款压缩包管理程序（包括管理归档中的应用备份）。`Proprietary`
