# 应用修改

**应用修改**让你能够修补、修改和扩展 Android 应用：应用补丁工具（**ReVanced/Morphe 风格**）、
修改版应用客户端（社交媒体、浏览器、YouTube）、签名与校验绕过，以及改变应用行为的 LSPosed 模块。
大多数条目需要 root（或 LSPosed）。

> [!NOTE]
> 点击条目后，`FOSS` 应用会打开其**源代码**页面（GitHub/GitLab 等），否则打开其
> **Google Play Store** 页面。

## 应用补丁工具

- **[⭐ Morphe](https://morphe.software/)** - 由部分 ReVanced 原开发者打造的新一代应用补丁工具。它提供现代化的界面、更高的稳定性，以及不断增长的受支持应用与功能列表。`FOSS`
- **[NexAlloy](https://github.com/NexAlloy/NexAlloy)** - ChsBuffer 的 LSPosed 模块，由 Morphe、ReVanced 驱动，支持多款应用。`FOSS` `[LSP]`
- **[Lucky Patcher](https://www.luckypatchers.com/)** - 应用补丁与修改工具（请谨慎使用）。`Proprietary`
- **[ReVanced](https://revanced.app/)** - 强大的应用补丁工具，可为 YouTube、Spotify 等热门应用添加额外功能与自定义选项。`FOSS`
- **[ReVanced Extended](https://github.com/NoName-exe/revanced-extended)** - ReVanced eXtended（现为 Morphe）的 YT 与 YT-M，root 与非 root 用户均可使用。`FOSS` `[M]` `[K]`
- **[ReVanced Magisk Module by j-hc](https://github.com/j-hc/revanced-magisk-module)** - 功能丰富的 ReVanced 与 morphe 构建器。`FOSS` `[M]` `[K]`

> 另请查看 [Morphe 补丁列表 ↗](https://morphe-patches.software/)
