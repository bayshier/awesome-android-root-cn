# 精简预装

**精简预装**用于移除你从未要求的预装臃肿软件和系统应用。这些精简预装应用和
Magisk/KernelSU 模块可在已 root 设备上卸载、冻结或隐藏不需要的应用包 - 提升隐私、续航和性能。


## 精简预装应用与模块

> [!TIP]
> **相关指南**：[完整精简预装教程](../general-guides/android-apps-debloating.md)

- **[⭐ Canta](https://github.com/samolego/Canta)** - 借助 [Shizuku](development.md#开发者工具) 在无 root 的情况下卸载任意应用。`FOSS` | [🌱](https://f-droid.org/en/packages/io.github.samolego.canta/) | [▶️](https://play.google.com/store/apps/details?id=io.github.samolego.canta)
- **[De-Bloater](https://github.com/sunilpaulmathew/De-Bloater)** - 借助 Magisk 的力量精简不需要的系统应用！`FOSS` | [🌱](https://f-droid.org/packages/com.sunilpaulmathew.debloater) | [▶️](https://play.google.com/store/apps/details?id=com.sunilpaulmathew.debloater)
- **[EXA System App Remover](https://play.google.com/store/apps/details?id=exa.free.saux)** - 立即卸载未使用的系统应用，移除臃肿软件、清理内存并为手机提速。`Proprietary`
- **[Scalpel](https://github.com/Enginex0/Scalpel)** - 面向已 root Android 的精准精简与系统化工具。`FOSS` `[M]` `[K]`
- **[System App Nuker](https://github.com/ChiseWaguri/systemapp_nuker)** - 通过 WebUI 界面精简系统应用的模块。`FOSS` `[M]`
- **[System app remover](https://play.google.com/store/apps/details?id=com.jumobile.manager.systemapp)** - 系统应用移除器和用户应用卸载器，支持应用移至 SD 卡、应用移至手机、SD 卡上 APK 的扫描/安装/删除。`Proprietary`
