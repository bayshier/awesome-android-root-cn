# 自定义

面向已 root Android 设备的**自定义**工具 - 主题与视觉美化、启动器、状态栏与导航栏调整、手势、字体与表情符号、通知、锁屏/熄屏显示（AOD）、屏幕与显示相关的应用，以及
Magisk/KernelSU/LSPosed 模块。


> [!TIP]
> 请务必查看 [ROM 与 OEM 自定义](system.md#system-ui-framework)一节，了解更多主题化和自定义选项。

## 字体与表情符号

- **[Emoji Replacer](https://play.google.com/work/apps/details?id=com.htetz.emojireplacer)** - 将系统表情符号替换为 iOS 16.4、Samsung、Google、JoyPixels、Facebook、Twemoji 等风格。`Proprietary`
- **[EvilFont](https://github.com/dedeadend/EvilFont)** - 将你的阿拉伯语/波斯语字体更改为 Teshrin + iOS 表情符号。`FOSS` `[M]` `[K]`
- **[Font Manager](https://play.google.com/store/apps/details?id=com.androidacy.fontmanager)** - Androidacy 出品的优秀字体与表情符号更换工具。`Proprietary`
- **[FontCraft Pro](https://github.com/RipperHybrid/FontCraft)** - 时尚的字体与表情符号，打造个性化体验。`FOSS` `[M]` `[K]`
- **[FontLoader](https://github.com/JingMatrix/FontLoader)** - 通过 Magisk 模块修改字体是常见需求。`FOSS` `[M]`
- **[G-Font Installer](https://xdaforums.com/t/development-magisk-module-g-font-installer.4617743/)** - 将 Google Play 和 Google Pixel 手机等大多数 Google 应用所使用的官方 Google 字体直接安装到你的手机上。`Proprietary` `[M]`
- **[JetBrains Font](https://github.com/Mars-Wave/jetbrains-font-magisk-module)** - 使用 JetBrains Mono 和 Magisk 让你的手机更美观。`FOSS` `[M]`
- **[KernelSU-iOS-Emoji](https://github.com/n4bi10p/Ios-emoji)** - 以 systemless 方式将表情符号字体替换为 iOS Emoji。`FOSS` `[K]`
- **[Magisk Fonts](https://github.com/JingMatrix/MagiskFonts)** - 为 Android 添加自定义字体，供系统全局使用。`FOSS` `[M]`
- **[Magisk-iOS-Emoji](https://github.com/Keinta15/Magisk-iOS-Emoji)** - 以 systemless 方式将表情符号字体替换为 iOS Emoji。`FOSS` `[M]`
- **[Magisk-Minecraft-Font](https://github.com/DethByte64/Magisk-Minecraft-Font)** - 将你的默认字体更改为 Minecraft 字体的 Magisk 模块。`FOSS` `[M]`
- **[MakeFontsGreatAgain](https://github.com/Numbersf/MakeFontsGreatAgain)** - 系统级字体覆盖器，具备独特的 GMS 伪装与多区间 Unicode 过滤功能。`FOSS` `[M]` `[K]`
- **[MiSans](https://github.com/adivenxnataly/MiSans)** - 用 MiSans 提升设备的字体体验。`FOSS` `[M]`
- **[Nastaliq Urdu Font](https://xdaforums.com/t/module-font-nastaliq-urdu-font.4645787/)** - 面向乌尔都语用户的 Nastaleeq 字体模块。`FOSS` `[M]`
- **[OneUI Emoji Pack](https://github.com/aloozchips/OneUIEmojiPack)** - 以 systemless 方式将 AOSP 表情符号包替换为 OneUI 表情符号包。`FOSS` `[M]` `[K]`
- **[Twemoji-Remastered](https://codeberg.org/Snowy/Twemoji-Remastered)** - 以 systemless 方式将手机表情符号替换为 Twemoji（Twitter 表情符号）。`FOSS` `[M]`
- **[Unicode Font Set](https://github.com/Losketch/UnicodeFontSet-magisk-module/blob/main/README.en.md)** - 通过 Magisk 框架安装一套全面的 Unicode 字体集和配置文件。`FOSS` `[M]`
- **[zFont 3](https://play.google.com/store/apps/details?id=com.htetznaing.zfont2&hl=en)** - 在 Samsung、Vivo、iQOO、LG、Huawei、Honor、OnePlus、ASUS、OPPO、Realme、Xiaomi、Tecno 和 Infinix 设备上更换自定义字体样式。`Proprietary`

## 手势与控制

- **[Multi Finger Gesture X](https://github.com/EliLei/MultiFingerGestureX)** - 一款为 Android 15+ 添加三指及以上手势支持的 LSPosed/Xposed 模块。`FOSS` `[LSP]`
- **[Ogesture](https://github.com/tanujnotes/ogesture)** - 在任意 Android 手机上配合第三方启动器使用手势导航。`FOSS` `[LSP]`
- **[OPPO/OnePlus side button enhancement](https://github.com/ItosEO/OplusKey)** - 自定义 Oppo 和 OnePlus 设备上侧边按键的行为。`Proprietary` `[M]`
- **[Recents](https://github.com/tymwitko/Recents)** - 与启动器无关的 Android「最近任务」菜单。`FOSS` `[LSP]`
- **[Three-Finger-Screenshot](https://github.com/hxreborn/three-finger-swipe)**- 三指滑动的独立 LSPosed 实现。`FOSS` `[LSP]`
- **[Volume Key Track Control Module](https://github.com/Hepolise/VolumeKeyTrackControlModule)** - 允许使用音量键切换曲目和播放/暂停。`FOSS` `[LSP]`
- **[Volume Scroll](https://github.com/farfromrefug/VolumeScroll)** - 使用音量键进行滚动的 Android 应用。`FOSS` `[M]`

- **[HyperOS App Vault](https://github.com/Mods-Center/HyperOS-App-Vault)** - 增强版 HyperOS 应用助理（App Vault），解锁小部件、高端机型特性、模糊调节和滚动动画。`Proprietary` `[M]` `[K]`
- **[HyperOS Launcher](https://github.com/Mods-Center/HyperOS-Launcher#hyperos-launcher-v5)** - 增强版 HyperOS 桌面，带来高端机型特性，包括可自定义的应用抽屉、图标包等。`Proprietary` `[M]` `[K]`
- **[Launcher3 QuickLaunch](https://github.com/hddq/launcher3-quicklaunch)** - 让你在 Launcher3 的应用抽屉搜索中按下回车键即可立即启动第一个搜索结果。`FOSS` `[LSP]`
- **[NovaInstaller](https://github.com/Minionguyjpro/NovaInstaller/)** - 将 Nova Launcher 安装到 Android 的 /system/app/ 目录。`FOSS`
- **[OnePlusPlusLauncher](https://github.com/wizpizz/OnePlusPlusLauncher)** - 一款面向 OnePlus OxygenOS 15 系统桌面的 Xposed 模块，提供更多实用功能。`FOSS` `[LSP]`
- **[Pixel Launcher Enhanced](https://github.com/Mahmud0808/PixelLauncherEnhanced)** - 解锁众多精彩功能，从自定义外观到添加更多功能等。`FOSS` `[LSP]`
- **[Pixel Launcher Mods](https://github.com/KieronQuinn/PixelLauncherMods/)** - 用于增强 Pixel Launcher 体验的修改模块。`FOSS`
- **[Root Activity Launcher](https://play.google.com/store/apps/details?id=tk.zwander.rootactivitylauncher)** - 借助 root 权限直接从主屏幕启动应用的 Activity。`Proprietary`

## 锁屏与熄屏显示（AOD）

- **[AlwaysOn](https://github.com/Domi04151309/AlwaysOn)** - 添加熄屏显示功能，提供表盘、行为和背景等多种自定义选项。`FOSS` `[LSP]`
- **[ColorOS Live Lyrics Bridge](https://github.com/Andrea-lyz/ColorOS-Live-Lyrics-Bridge)** - 将受支持播放器的逐句歌词接入 ColorOS/OPlus 锁屏歌词管线。`FOSS` `[LSP]`
- **[HyperGlow](https://github.com/amarinne/hyperglow)** - 为 HyperOS 3 提供动画化的锁屏与熄屏显示歌词。`FOSS` `[LSP]`
- **[HyperOS AOD](https://github.com/Mods-Center/HyperOS-AOD)** - 功能解锁的增强版 HyperOS AOD 与锁屏编辑器应用。`Proprietary` `[M]` `[K]`

## 通知

- **[HyperIsland](https://github.com/1812z/HyperIsland/blob/main/README_EN.md)** - 由 LSPosed 驱动，为 HyperOS 3 带来灵动岛风格通知。`FOSS` `[LSP]`
- **[Notification Code](https://gitlab.com/n00byara/NotificationCode)** - 自动从通知中提取验证码和其他有用信息。`FOSS` `[LSP]`
- **[Notification Icon Fix](https://github.com/Xposed-Modules-Repo/io.github.howard20181.notificationiconfix/)** - 面向 AOSP、MIUI 和 HyperOS 的模块，使用算法将白色通知图标转换为可辨认的图标。`FOSS` `[LSP]`
- **[Punch-hole Download Progress](https://github.com/hxreborn/punch-hole-download-progress)** - 在摄像头挖孔周围以动画圆环显示下载进度。`FOSS` `[LSP]` | [🌱](https://apt.izzysoft.de/fdroid/index/apk/eu.hxreborn.phdp)

## 屏幕与显示

- **[Adaptive Theme: Auto Dark Mode by Ambient Light](https://github.com/xLexip/Adaptive-Theme)** - 利用环境光传感器在浅色和深色模式之间自动切换。`FOSS` | [▶️](https://play.google.com/store/apps/details?id=dev.lexip.hecate)
- **[Anti Brightness Change](https://github.com/binarynoise/XposedModulets)** - 阻止任何应用更改屏幕亮度。`FOSS` `[LSP]` | [🌱](https://apt.izzysoft.de/fdroid/index/apk/com.programminghoch10.AntiBrightnessChange)
- **[DarQ Fork](https://github.com/Arora-Sir/DarQ)** - 为 Android 10 及以上版本提供可按应用选择的强制深色选项。`FOSS`
- **[DPIS](https://github.com/Kwensiu/DPIS)** - 用于按应用调整界面缩放、最小宽度和字体大小的 LSPosed 模块。`FOSS` `[LSP]`
- **[Keep Screen Off](https://github.com/Xposed-Modules-Repo/com.ncyxie.keepscreenoff)** - 通过忽略 `FLAG_KEEP_SCREEN_ON` 和屏幕唤醒锁，阻止选定应用让屏幕保持常亮。`FOSS` `[LSP]`
- **[Pointer Replacer](https://github.com/thesandipv/pointer_replacer)** - 替换用户触摸屏幕时出现的圆点[需要在开发者选项中开启「显示触摸操作」]。`FOSS` `[LSP]`
- **[Pseudo DC Dimming](https://github.com/dantmnf/PseudoDCDimming)** - 通过软件亮度增益，为某些 OLED 屏幕在低亮度下启用替代调光模式（类似 DC 调光）。`FOSS` `[LSP]`
- **[PureShot](https://github.com/kazutoiris/PureShot)** - 隐藏状态栏、导航栏、弹窗、画中画、Toast 等。`FOSS` `[LSP]`
- **[Rotation Suggestions Closed](https://github.com/Astoritin/RotationSuggestionsClosed)** - 旋转屏幕时不再显示旋转建议按钮。`FOSS` `[M]`
