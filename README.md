## 什么是 Awesome Android Root？

Awesome Android Root 是一个由社区精心维护的知识库，专注于 **Android 设备 root 以及充分发挥 root 权限的价值**：

- **Root 指南** - Magisk、KernelSU、APatch、LSPosed、Bootloader 解锁以及特定设备的详细教程（Pixel、Samsung、Xiaomi、OnePlus、Nothing、Motorola）。
- **应用与模块数据库** - 650+ 精选 root 应用、Magisk 模块、KernelSU 模块、APatch 模块以及 LSPosed/Xposed 模块，每一条目均附有源码链接、F-Droid/Play Store 徽章和许可证信息。
- **教程、常见问题与故障排除** - 广告拦截、精简预装、Play Integrity、bootloop（无限重启）等内容。
